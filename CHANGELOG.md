# Changelog

## 0.3.0 - 2026-08-08

### Features

- Rebuild the core loop around council-led organization management, three persistent resources, officer assignments, recruitment, formula research, branches, sealed artifacts, and player-led missions.
- Add a persistent autonomous world with private agent memories, social relations, auditable world events, and deterministic faction strategy across contested Backlund locations.
- Add all 22 standard pathways and 220 sequence dossiers, backed by lore evidence and used by opening choices, ability limits, organization effects, advancement, and long-term simulation.
- Add a conserved high-sequence asset ledger for 22 Uniquenesses, nine Sefirot groups, and named Sequence 4–1 characteristics.
- Extend the campaign from Backlund to Tingen, Bayam, Bansy, the City of Silver, Trier, and Cordu, with dynamic local pressure, branch yields, historical stages, deification, and post-deity weekly governance.
- Add structured long-term memory, knowledge audiences, generative ability envelopes, deterministic fate aberrations, and recoverable loss-of-control states.
- Bundle authorized runtime knowledge seeds in signed installers and initialize the local RAG index on first launch without distributing source novels.

### Fixes

- Serve vinext production CSS and JavaScript correctly on Windows by normalizing static-file cache keys during installation and startup.
- Open the council order composer automatically when a city investigation or branch command is seeded from the campaign panel.
- Harden release seed validation, knowledge-horizon persistence, RAG consistency, IPC timeouts, CI type checking, dependency auditing, and source/artifact provenance.

### Documentation

- Document the seven-stage campaign, complete pathway and high-sequence ledgers, v21 save migration, Windows runtime compatibility, QA gates, and protected Windows release process.
