# 第四阶段：真实势力经营闭环与玩家亲历场景

## 本阶段目标

- 地图、敌意、外交和世界势力统一使用八个真实贝克兰德势力 ID。
- 战略点从抽象节点改为可争夺的机构、渠道、网络和具体地点。
- 闭合“控制战略点 → 建分部 → 获得钱/人力/材料/情报 → 核验配方 → 提拔非凡者 → 扩大控制”的经营循环。
- 玩家亲自带队时，事实先由规则锁定但不公开；场景必须暂停等待自由命令，结束后才继续世界和文学推演。

## 知识库边界

贝克兰德城市结构、教会与国家关系、工业和阶层结构使用以下知识库记录作为设计依据：

- `lotm-08-007`：贝克兰德城市、议会、教会、贫民与隐秘组织。
- `lotm-06-001`、`lotm-07-001`：正神教会及其公开/秘密职能。
- `lotm-07-003`：极光会与污染性活动。
- `lotm-07-010`：魔女教派、政治渗透和灾祸活动。
- `lotm-11-001`、`lotm-11-002`、`lotm-11-003`、`lotm-11-004`：工业、阶层、货币和教会—国家关系。

具体街区网络由上述已验证世界规则和项目已有贝克兰德地点组合生成，标记为 `local-fiction`；三十个项目既有地标战略点标记为 `verified`。魔药配方没有知识库证据时，研究进度最多到 99，不能用于提拔或晋升。

## 失败语义

亲历场景没有本地降级叙事。模型调用失败会保留已经锁定的事实和玩家场景进度，界面继续锁定并显示接入错误；玩家可原样重试，不会重新掷出行动结果。
