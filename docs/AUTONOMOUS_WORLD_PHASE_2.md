# 自治世界第二阶段：持续角色、私有决策与社会关系

## 目标

第二阶段让重要角色和势力成为跨周持续存在的行动主体，而不是每周由模型临时生成的一段背景文字。

每个自治主体必须拥有：

- 稳定身份与长期驱动力；
- 当前目标、上一行动与规划周期；
- 只属于自己的事件和知识记忆；
- 与其他主体之间可持续变化的熟悉度、紧张度和筹码；
- 基于自身认知生成的行动候选，同时保留自由行动能力。

## 每周流程

1. 从持久世界内核补齐角色和势力档案。
2. 按角色或势力分别投影可见的观察、知识和关系。
3. 为每个主体构建私有决策帧和有限的行动候选。
4. 世界模型可以选择候选行动，也可以根据已知信息提出自由行动。
5. 新知识必须通过事件、观察或知识节点声明来源与持有者。
6. 规则层应用世界增量，然后更新目标、记忆、反思和社会关系。
7. 自治状态摘要进入世界账本快照，与其他权威事实一起提交。

## 硬约束

- 一个主体不能读取其他主体的私有观察、知识或记忆。
- 模型不能让角色因为世界模拟器看到了真相就自动知道真相。
- 没有来源的认知不得写入主体记忆。
- 新角色、新势力和关系必须跨周保持稳定 ID。
- 模型生成失败时不提交自治状态、世界状态或账本快照。
- 候选行动不是固定菜单，不限制 AI 游戏的自由行为。

## 当前验收范围

- 新游戏为所有持久角色和势力建立自治档案。
- AI 世界回合接收隔离后的自治决策帧。
- 世界回合结束后更新私有记忆、目标、反思和社会关系。
- 新出现的角色与势力会自动补齐自治档案。
- v15-v17 存档迁移到 v18 时补齐自治状态并保留原世界内核。
- 世界账本快照包含自治主体与社会关系的权威投影。

## 私有动态记忆投影

每个独立规划请求都会构建显式受众的动态记忆切片，而不是复用全局世界上下文：

- actor 只能读取自己的信念、自己参与的承诺、涉及自己的关系来源、自己拥有或参与的计划，以及自己参与或观察的事件；
- faction 使用独立的 faction 受众类型，按组织 ID 和规范化 `faction:<id>` 引用读取相关事件、信念、承诺、关系与计划，绝不使用 actor ID 冒充；
- 投影最多 12 个引用、2,800 字符，同时把正文与引用 ID 写入 `AgentPlanningProjection`；
- 只有整周成功提交后才为对应 actor/faction 写入幂等 `delivered` 和 `presented` 回执，失败、取消和重试不写回原状态。

## 结构化反思闭环

反思是持久化的 `AutonomousReflection`，包含创建周、受众、摘要、结论、来源事件/记忆 ID、建议目标/意图、所需知识、驱动力信号和来源类型。它由主体可见的 WorldKernel 投影与已经过权限过滤的动态记忆确定性归纳，不增加可能造成半周提交的模型调用。

上一周反思和长期驱动力会进入下一周 `AutonomousDecisionFrame`，并生成有来源的候选行动；因此反思可以改变下一轮目标、意图或提案依据。旧存档中的字符串反思会确定性迁移为结构化记录并保留原文。

来源权限、持久化、迁移、决策影响和失败原子性由 `tests/autonomous-agents.test.mjs` 与 `tests/turn-transaction.test.mjs` 覆盖。
