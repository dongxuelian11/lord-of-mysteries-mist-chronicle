# 有界自治世界与真实模型可靠性

## 目标

世界可以持续推演，但任何一次周结算都必须有界、可审计、可失败。模型失败直接报错；系统不会用模板事件、模板小说或本地猜测代替模型输出。

## 周回合边界

1. 规则层先把玩家自由命令整理为行动契约并锁定红线。
2. 最多 24 个活跃角色或势力从同一周起点独立形成提案；冷主体保留在持久世界中，需要时再回到活跃集。
3. 世界裁决器只接收相关角色、地点、项目、近期事件和已授权知识。裁决 payload 有 72,000 字符硬上限。
4. 世界事实与组织结算先提交，随后才生成玩家可见的文学章节。文学失败只重试文学层，不重复世界结算。
5. 推演期间 UI 保持锁定；玩家看不到尚未完成文学呈现的后台事实。

## 局部修复

- 公开消息重复：冻结世界事实，只重写 2–4 条报纸、公告或行业消息。
- 行动报告越界：冻结行动成败和世界事件，逐份重写违规报告。
- 文学越权：只改写违规段落，其他段落保持不变。
- Agent Schema 错位：已授权知识 ID 若误填到目标栏，会确定性归位到知识依据；未知裸 ID 仍拒绝。

每类模型修复最多两次。两次仍不合格就直接报错，不生成降级文本。

## 长期 Prompt 控制

裁决输入按以下顺序收缩：近期世界与公开消息、证据和时间线、组织旁支数据、势力历史、地图/高位账本历史、可恢复描述文本。以下内容永不由压缩器裁剪：

- 本周全部玩家行动契约；
- 全部活跃 Agent 提案；
- 玩家红线与撤退条件；
- 世界和组织输出协议。

## 真实模型验收

2026-08-09 使用本机安全存储中的 DeepSeek 配置完成连续 20 周回归：

- 20 个已提交世界快照；
- 77 条公开消息；
- 每周文学章节 3–5 节、6–15 个自然段，全部非空；
- 单周世界与文学总耗时约 30–66 秒；
- 第 16–20 周继续通过 Prompt 硬预算；
- 没有模板降级、世界回滚或重复结算。

运行方式：

```powershell
# 使用环境变量
$env:DEEPSEEK_API_KEY="..."
node scripts/real-week-regression.mjs 20

# 使用桌面端 safeStorage 中已经保存的 Key，不打印、不落盘明文
npx electron scripts/secure-real-week-regression.cjs 20

# QA 中断后从系统临时目录的最后完整周继续
npx electron scripts/secure-real-week-regression.cjs 20 --resume
```

断点文件仅用于开发 QA，不属于正式游戏存档格式，也不包含 API Key。

## 证据边界与后续验收

上述 DeepSeek 连续 20 周记录只证明当时配置下的技术可靠性：Prompt 保持有界、事务没有重复结算或回滚、文学输出非空。它不证明玩法有趣、社会涌现可信、长期行动多样，也不是 5–20 小时真人体验。

结构化自动涌现指标、输入格式和跨模型比较见 [EMERGENCE_EVALUATION.md](./EMERGENCE_EVALUATION.md)。真人长线验证必须独立执行 [HUMAN_LONG_PLAYTEST_PROTOCOL.md](./HUMAN_LONG_PLAYTEST_PROTOCOL.md) 并使用空白会话模板；截至 2026-08-09，仓库没有已完成的真人长线体验数据。
