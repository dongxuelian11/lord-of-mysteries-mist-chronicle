# 第五至第七阶段：全途径账本、跨城战役与成神后世界

状态：已实现并通过自动化测试与桌面/移动视口 UI 验收。

## 阶段目标

这一阶段把第一至第四阶段的贝克兰德组织经营闭环延伸为长期世界线：玩家仍从议会治理组织，但可以沿知识库约束的 22 条标准途径持续晋升，在其他城市建立分部，经历多段重大历史，并在序列 0 之后继续治理世界。

大雾霾只是首个重大阶段，不再是游戏终点。规则层继续先结算事实，再让模型生成玩家可见的文学叙事；模型接入失败会明确报错，不会用本地文本降级或重掷结果。

## 22 条途径与 220 个序列档案

`app/pathway-sequence-ledger.ts` 为 22 条标准途径建立了序列 9 至序列 0 的完整档案，共 220 条。每条档案包含：

- 序列名称、层级、源质与旧日方向；
- 知识库证据 ID；
- 可操作能力边界和默认作用尺度；
- 对组织治理的宏观贡献；
- 扮演提醒与失控风险。

这些档案同时约束开局选择、能力标签、组织贡献、晋升展示和高位世界推演。具体配方、仪式、克制关系与单项能力仍必须在相应知识记录进入角色权限后才能使用，不能仅凭序列名称补写。

## 高位资产唯一账本

`app/high-sequence-ledger.ts` 维护独立于叙事文本的权威账本：

- 22 份途径唯一性；
- 9 份源质及其相邻途径分组；
- 序列 4 至序列 1 的具名非凡特性；
- 每项资产的持有者、状态、地点、来源事件和流转历史。

同一途径不能生成第四份序列 1 特性；已经被持有的唯一性或源质不能被另一主体直接领取，必须先由世界行动形成争夺或转移。序列 0 晋升要求对应途径的三份序列 1 特性和唯一性，容纳后会在账本中标记，不允许叙事模型绕过。

## 跨城世界

当前长期世界包含七座可持续推演的城市：

| 城市 | 战略侧重 | 初始状态 |
| --- | --- | --- |
| 贝克兰德 | 议会、教会、工业、码头与工人社区 | 已建立落脚点 |
| 廷根 | 大学档案、值夜者辖区、地下交易与中产社区 | 已知 |
| 拜亚姆 | 港务、反抗军、风暴教会与海盗黑市 | 已知 |
| 班西 | 异常港务、灾祸遗痕、幸存者与隐秘海路 | 已知 |
| 白银城 | 探索队、怪物材料、议事传统与信仰锚点 | 已知 |
| 特里尔 | 政治、工业、地下遗迹、镜中异常与艺术网络 | 已知 |
| 科尔杜 | 村庄关系、循环梦境、仪式灾难与边境交通 | 已知 |

每座城市有自己的情报、控制、地方压力、投入人力、持续产出和战略区块。调查会把公开消息和特殊渠道情报挂到具体城市；建立分部会占用人力并带来钱、非凡材料和情报，但地方势力每周仍会施加反制压力。分部不会永久冻结控制力。

城市行动仍从议会发起。玩家在“组织”中的跨城面板选择城市并点击“探查城市”或“筹建分部”后，会回到议会并自动打开已经填好意图的决议输入框，玩家可以继续自由修改命令。

## 历史阶段与长期推进

世界账本登记了从第一纪至第五纪的历史底图，并按当前世界状态推进七个战役阶段：

1. 贝克兰德奠基；
2. 贝克兰德大雾霾；
3. 跨城组织网络；
4. 大陆与海上博弈；
5. 末日前奏；
6. 成神与神国治理；
7. 成神后世界。

阶段由周数、序列、重大事件结果和已建立的跨城节点共同决定。阶段变化、城市行动和公开信号都写入带知识库证据的战役事件记录，因此历史不会只存在于模型上下文中。

## 成神后治理

玩家到达序列 0 后，游戏不会进入结局画面。每周继续结算：

- 锚强度与人性；
- 祈祷积压；
- 权柄压力；
- 受保护城市；
- 外神压力；
- 神国长期项目和世界事件。

这些状态会继续进入世界模型的受约束决策帧。模型只能解释已经结算的变化，不能用一段“成神结局”替代持续模拟。

## UI 与操作边界

- 跨城、历史阶段、22 途径档案和高位资产集中在组织页的同一块长期世界面板，避免增加新的顶层导航。
- 桌面视口 `1280×720` 与移动视口 `375×812` 均已验收，无横向溢出。
- 推演期间全屏锁定，不能切换其他界面；事实保持隐藏，文本按顺序生成。
- 需要玩家决断时暂停推演，等待自由命令。
- 模型失败直接显示接入错误并保留已锁定事实，不提供本地降级叙事。

## 存档迁移

当前存档 schema 为 v21。v15 至 v20 存档导入时会补齐组织经营、自治主体、势力战略、亲历场景、高位资产账本和跨城战役状态，同时保留原有世界内核、动态记忆和知识权限边界。校验和失败或缺少关键世界状态的存档会明确拒绝，不会静默改写。
