# 生成式能力、低频命运异常与轻量失控框架（MVP）

## 定位

本任务不建立最终版复杂规则系统，而是守住建边界的三个轻量机制：

```text
AI 负责理解、创造方案和叙事
轻量规则负责边界、资源和结果一致性
世界状态负责最终真值
动态记忆负责长期连续性
```

必须守住的边界只有：AI 不能随意突破能力领域、不能制造无限资源、不能修改已结算结果、一次普通失败不能让角色永久退场、命运异常和失控不能混为一谈、读档/重试/叙事重写不能重新掷骰。除此之外尽量保留灵活度。

## 生成式能力（app/ability-generation/）

能力不是固定技能卡列表。玩家可以自由描述用法（火焰加热门锁、让目标忽略物品、判断是否有人干扰、隐藏声音与注意力、转移物品等），AI 输出轻量 `ProposedAbilityPlan`，规则层只做包络裁剪：

```text
ACCEPT
ACCEPT_WITH_LIMITS
ACCEPT_AS_IMPROVISED_EFFECT
REQUIRES_PREPARATION
REQUIRES_CLARIFICATION
REJECT_OUTSIDE_ABILITY_DOMAIN
```

合理但未预注册的方案优先 `ACCEPT_WITH_LIMITS`，不会因为没有预定义动作名而直接拒绝。规则层只返回方案信封，不建立永久效果类型。20 个开发者未预注册用法的评测要求六种判定全部出现，且不能全收也不能全拒。

## 低频命运异常（app/fate/ 参数与冷却调整）

保留独立命运骰、命运压力、四种交叉、36 模板、动态记忆与防读档重骰，只调整触发节奏：

- 目标频率：普通 3%–5%、危险 7%–12%、强行 12%–18%、极端 18%–25%；
- 任意异常后至少 2 次能力行动不触发；同一周最多 1 次；
- 三级异常至少间隔 4 周；四级至少间隔 30 周且一局最多 1 次；
- 普通路线不出现四级（四级解锁需要大型仪式/高污染/越级/世界线偏离等真实高风险因素，仅压力高不足以解锁）；
- 压力增长放缓：普通未触发 +3、危险额外 +2、强行额外 +4；
- 触发后：一级压力降到 4 以内、二级 2 以内、三四级清零。

36 个模板仍是结构示例、测试基准与无模型兜底；AI 可以生成现场化事故，但规则层冻结极性、严重度、错位类型、允许的长期后果类型、禁止事项与至少一个恢复/利用钩子，AI 候选验证失败时使用固定模板兜底，不重新抽骰。

## 轻量失控框架（app/loss-of-control/）

角色只增加 `ControlState`（stability/pollution/mentalLoad/stage/recentRisk/activeSymptoms，外加 MVP 内部幂等账本）：

```text
stable → disturbed → critical → partial-loss → contained-loss
```

风险值 = 污染 + 精神负荷 + 灵性枯竭 + 连续反噬 + 强行施展 + 越级压力 − 休息 − 同伴支持 − 防护与治疗。

只在以下情况判定：风险达到阈值、当前行动产生明显污染或 backlash、critical 后继续强行施展、发生三级/四级命运异常、仪式严重失败。

硬限制：

- stable 不能因一次普通行动直接进入 partial-loss；
- 普通 failure 不自动触发失控；
- 命运异常不自动等于失控（命运事件增加风险，但最高只到 critical/disturbed 级别）；
- partial-loss 必须有前兆或高风险来源；
- contained-loss 必须带恢复计划；
- 失控结果确定性、防读档重骰。

恢复支持休息、暂停能力、队友陪伴、仪式治疗、净化、离开污染源、组织监护、完成恢复任务；不能一键清空，每次恢复动作花费一周并确定性降低风险，同时削减污染与精神负荷。

## 三层结算

```text
正常能力合同 → 命运异常合同 → 简化失控判定 → 三份合同原子应用
→ 世界事件和动态记忆 → AI 叙事
```

命运异常造成的污染进入失控判定；普通 backlash 增加风险但不自动失控；失控的无意识效果写进合同；叙事重试不重新结算；合同冲突 fail closed；不修改动态记忆模型。

## 命令

```text
npm run ability:generative:eval   # 20 个自由能力方案，六种包络判定
npm run fate:frequency:eval       # 4×10 万次低频分布与冷却不变量
npm run control:eval              # 失控行为评测（触发/阶段/恢复/幂等/边界）
npm run control:longrun           # 三条 30 周路线（正常/高风险/污染偏离）
```

## 避免锁死未来重构

- 新机制全部独立模块，通过公开接口连接能力引擎；
- 参数集中在各模块 config，不散落业务代码；
- 不要求 UI 依赖具体状态字段；世界推进不硬依赖失控公式；
- 临时参数不写进原著 canon 数据，文档标记为 MVP 游戏参数；
- 风险公式可替换策略，而不是最终规则；以后可增加魔药、扮演、晋升、锚而不推翻合同接口。
